OJS SVG Magic Move Demo

Not Yet Supported

None of the sequences on this page currently animate — every transition below hard-cuts instead of morphing. D3, Observable Plot, and Vega-Lite (via {ojs}) all produce fully compatible SVG shapes (<circle>, <rect>, <path>, <line>, <text>), but Quarto’s Observable JS cells render after Reveal’s ready event, while this extension only scans for SVG content once, synchronously, at ready. So the SVG magic-move feature never activates for {ojs}-rendered charts, regardless of shape compatibility. Kept here as a reference for what real {ojs}-rendered SVG looks like, pending a fix upstream.

Vega-Lite Points - Layout 1

vegaEmbed = require("vega-embed@6")
vlSpecA = ({
  $schema: "https://vega.github.io/schema/vega-lite/v5.json",
  width: 400,
  height: 300,
  data: {values: [{x: 1, y: 1}, {x: 2, y: 3}, {x: 3, y: 2}]},
  mark: "point",
  encoding: {
    x: {field: "x", type: "quantitative"},
    y: {field: "y", type: "quantitative"}
  }
})
{
  const div = document.createElement("div");
  await vegaEmbed(div, vlSpecA, {renderer: "svg", actions: false});
  return div;
}
